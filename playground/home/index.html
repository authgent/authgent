Run your own OAuth 2.1 server for AI agents.

Open-source alternative to Auth0, Okta, and Keycloak for the agent era. Reference implementation of draft-ietf-oauth-identity-chaining-14 and draft-ietf-oauth-transaction-tokens-08. Tested with Claude Desktop, Cursor, Continue, VS Code MCP, and ChatGPT.

DELEGATION
Multi-hop act chains

RFC 8693 token exchange with nested act claims; depth and scope-narrowing enforced per hop. Signed delegation receipts close the chain-splice attack.

CROSS-DOMAIN
Identity chaining

Cross-trust-domain delegation: Domain A mints a short-lived JWT grant; Domain B redeems it via jwt-bearer. Single-use, audience-bound, no refresh tokens.

TXN TOKENS
Transaction context

Short-lived typ: txntoken+jwt with txn, tctx, rctx. Scope-subset enforced. Propagate authorization context through internal call chains.

DPoP
Sender-constrained

RFC 9449 DPoP on by default. Tokens bound to the holder's key; useless if stolen from logs.
